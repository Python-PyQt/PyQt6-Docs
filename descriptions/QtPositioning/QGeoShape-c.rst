The :sip:ref:`~PyQt6.QtPositioning.QGeoShape` class defines a geographic area.

This class is the base class for classes which specify a geographic area.

For the sake of consistency, subclasses should describe the specific details of the associated areas in terms of :sip:ref:`~PyQt6.QtPositioning.QGeoCoordinate` instances and distances in meters.

This class is also accessible in QML as `geoShape <https://doc.qt.io/qt-6/qml-geoshape.html>`_.
